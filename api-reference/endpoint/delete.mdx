---
title: 'Delete Plant'
openapi: 'DELETE /plants/{id}'
---

Delete a single plant by its unique identifier.

## Authentication

Requires a Bearer token in the `Authorization` header.

## Path parameters

- **id** (integer, required): ID of the plant to delete

## Responses

- **204**: Plant deleted (no content)
- **400**: Returns an `Error` object describing the issue

## Examples

### cURL

```bash
curl -X DELETE "http://sandbox.mintlify.com/plants/12345" \
  -H "Authorization: Bearer $API_TOKEN"
```

Example error response (400):

```json
{ "error": 400, "message": "Invalid plant id" }
```

### JavaScript (fetch)

```javascript
const token = process.env.API_TOKEN;

async function deletePlant(id) {
  const res = await fetch(`http://sandbox.mintlify.com/plants/${id}`, {
    method: "DELETE",
    headers: {
      Authorization: `Bearer ${token}`,
    },
  });

  if (!res.ok && res.status !== 204) {
    const err = await res.json();
    throw new Error(`${err.error}: ${err.message}`);
  }
}

deletePlant(12345).catch(console.error);
```

### Python (requests)

```python
import os
import requests

token = os.getenv("API_TOKEN")
headers = {"Authorization": f"Bearer {token}"}

resp = requests.delete("http://sandbox.mintlify.com/plants/12345", headers=headers)
if resp.status_code not in (200, 204):
    print(resp.json())
    resp.raise_for_status()
```
